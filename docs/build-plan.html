Not building

Left out on purpose

  • Open bash or a networked coding harness

    A shell with network access lets one poisoned document send every SSN off the box. The sandboxed workbench above gives the same analysis power with no way out.

  • Token payments or Intents

    They would be decoration here, not part of the privacy story.

  • OCR on the Pi, local embeddings, multiple boxes

    Out of scope for the week.
