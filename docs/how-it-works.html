How the Family Privacy Box Works

One Raspberry Pi at home holds the family's SSNs, W-2s, passports and health records. Anyone in the family can ask ChatGPT or Claude about them. The assistant gets a checked answer and never sees the documents.

answered

Mom asks Claude: "What was our AGI last year, and do we need Maya's SSN for the FAFSA?"

Claude gets: "AGI $142,310, up 6%. Yes. Maya's SSN is on file, ending in 4320. The full number is on your phone."

blocked

Maya's ChatGPT asks: "What did the doctor say at Mom's last visit?"

Stopped before any search. Mom's health folder is not Maya's, so none of it ever reaches NEAR.

What backs each promise

Proven by hardware

  • The model runs in a real Intel TDX + NVIDIA enclave
  • The proof is fresh (uses the Pi's own random nonce)
  • Answers are signed by the enclave's key

Enforced by the Pi

  • Each person reaches only their own folders
  • Full SSNs never go back to an assistant
  • Health details and anything unusual need the owner's approval
  • Every answer that left is logged

Not covered

  • Someone with admin access to the Pi itself
  • A stolen Pi that is still plugged in (once unplugged, its files are encrypted)
  • Timing and size of requests, which NEAR can see
