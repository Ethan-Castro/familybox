The problem

Every family has a drawer like this. AI help means emptying it into a chatbot.

Pasted once, kept forever

Ask an assistant to fill a FAFSA and it now holds every SSN on the form, in a service you don't control.

Everyone sees everything

Shared folders don't know that a teenager's counseling referral or a parent's diagnosis belongs to one person.

"Private AI" stops at the model

A secure enclave proves where a model ran. It says nothing about what that model then tells the assistant that asked.

How it works

The assistant never touches the files. The box checks every answer.

Indigo is data moving, a lock means it is encrypted to the NEAR enclave, red means the box stopped something.

  1. Who is asking

    Each family member's assistant has its own connection, so the box always knows the person.

  2. Verify first

    Before every question the box checks NEAR's Intel TDX and NVIDIA attestation itself. Any failure stops the question.

  3. Encrypted to the enclave

    The question, tool calls and file text are end-to-end encrypted to the attested model key.

  4. Only your files

    The model can search and read only the asker's folders plus shared ones. Health records are owner-only, even for parents.

  5. Signed every turn

    Each model reply must carry the enclave's signature. Anything else stops the question. Nothing falls back.

  6. The answer gate

    The box knows the real SSNs, IDs and diagnoses in the files and catches them however they're written. Full values go only to the owner's own screen.

What it proves

Clear about what is proven, what is enforced, and what is not covered.

Proven by cryptography

  • The model ran in a genuine Intel TDX and NVIDIA confidential-computing enclave.
  • Questions, tool calls and file text were readable only inside it.
  • Each answer came from the attested model key.

Enforced by the box's code

  • Each person's assistant reaches only their own files.
  • The assistant receives only what passed the answer gate.
  • Full values reach only the owner's own screen.

Not covered

  • Anyone with root on the box can read everything.
  • NEAR's gateway still sees metadata: sizes, timing, the API key.
  • A fact the box doesn't know is sensitive relies on the reworded-leak check.

What's next

The same box, without the Pi.

A Raspberry Pi is a good always-on home for the box. The next step is letting a family use a device they already own. Everything in this section is planned, not built.

familybox app

Install the box on a family laptop or desktop you already trust.

  • Same answer gate, approvals, trust timeline and NEAR verification.
  • Files encrypted at rest, unlocked when the app is open.
  • Approvals and alerts on a phone companion.
  • A Mac sandbox for the analysis workbench (today it needs Linux).
planned

familybox key

The whole box on an encrypted flash drive. Plug it in, unlock it, ask; unplug it and nothing stays behind.

  • Portable mode: runs from the drive on the computer it's plugged into.
  • Boot mode: starts the computer into a small Linux box system, so the host's own OS never sees the files.
  • Documents, keys and logs live only on the drive, encrypted.
  • The drive is the thing you lock in the drawer.
planned

Raspberry Pi box

What runs today: always on at home, so assistants can reach it any time and the analysis sandbox works out of the box.

  • Installs with one script, no sudo.
  • 693 tests; 691 pass on the Pi 5 itself.
  • Checks NEAR's proof on-device in 1.6 to 5 seconds.
available now

What changes on a personal device

  • The box is only as private as the device it runs on. A Pi does one job; a family laptop also runs a browser, email and everything else. Boot mode on the key avoids trusting the host OS.
  • It only answers while it's running. An app or a key that's unplugged means assistants get "the box is offline", never a fallback.
  • Losing a key must not lose the data. Encrypted backups (already built) and a recovery code come first.

Try it

Two minutes, no API key.

Without a key the box replays recorded enclave conversations for the demo questions. Its real tools, access checks and answer gate still run.

# Python 3.12+ and uv
git clone https://github.com/Ethan-Castro/familybox && cd familybox
uv sync
export FAMILYBOX_HOME=$PWD/demo        # a fictional family: Dana, Sam and Maya

uv run familybox ask --as maya "What medications am I on?"
uv run familybox ask --as maya "What did the doctor say at Mom's last visit?"
uv run familybox pending --as maya     # values held for Maya's approval
uv run pytest -q tests
