Tricks don't work

The box knows your real numbers, so it can spot them.

Spelled out, written backwards, split into pieces, or demanded by a sneaky note hidden in a file. The box checks every answer against what is actually in your documents before your assistant sees it.

What you can do with it

Made for a real household.

Ask in plain words

"What do we still need for the college aid form?" Use ChatGPT, Claude or the coding assistants you already have.

Approve on your phone

When an answer needs a full number, it waits for its owner. Tap, and it shows on your screen only.

Snap a photo

Take a picture of an insurance card or a tax form. The box reads it and starts protecting the numbers on it.

Fill in forms

The assistant plans the form. The box writes in the real numbers and hands the finished PDF only to you.

See everything that happened

A simple timeline shows each question, which files were opened, and what was held back.

Back up safely

Copies saved to the cloud are locked before they leave home. The cloud only ever holds a sealed package.

Straight talk

What we promise, and what we don't.

We promise

  • Your files stay on your box. Assistants never get a copy.
  • The AI that reads them runs sealed, and the box checks the seal before every question.
  • Full numbers go only to their owner's own screen.
  • If any check fails, you get no answer instead of an unsafe one.

We don't promise

  • Protection from someone who can log in to the box itself.
  • That a clever hint in other words can never slip through.
  • Anything about a value after you approve it onto your own screen.
Under the hood, for the technical reader

The model runs in NEAR AI Cloud inside a trusted execution environment (Intel TDX with NVIDIA confidential computing). Before every question the box verifies fresh hardware attestation itself, end-to-end encrypts the question, tool calls and file text to the attested model key, and requires an enclave signature on every model turn. It fails closed.

Assistants connect over MCP and have no tool that lists or reads files. A deterministic answer gate matches every reply against the protected values indexed from the family's files; a second attested model call looks for reworded leaks. The box also fingerprints NEAR's serving code and pauses when it changes. In testing it caught NEAR running two versions of one model's serving stack at once.

693 automated tests; 691 pass on a Raspberry Pi 5. Full results, the threat model and every measurement are in the repository. Built at NEAR Hackathon 2026.

What changes on your own device

  • It's as private as the device. A home box does one job. A laptop also runs your browser and email, so the key can start the computer in its own clean mode.
  • It answers only while it's on. Closed app or unplugged key means "the box is away", never a less safe shortcut.
  • Losing the key can't mean losing your files. Locked backups and a recovery code come first.

Try it

Comfortable with a terminal? Two minutes.

The demo uses a made-up family and needs no account or key.

# needs Python 3.12+ and uv
git clone https://github.com/Ethan-Castro/familybox && cd familybox
uv sync
export FAMILYBOX_HOME=$PWD/demo

uv run familybox ask --as maya "What medications am I on?"
uv run familybox pending --as maya   # what's waiting for Maya's OK
